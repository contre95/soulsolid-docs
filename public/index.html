Soulsolid

Music software for the music hoarder

Read the docs Try the demo GitHub

Built for the music hoarder

Everything you need to keep a large local library in shape.

Library

Browse albums, artists and tracks, edit their tags and stream them from the browser.

Import

Import whole directories, with duplicate detection and a queue to review what comes in.

Download

Pluggable downloaders: drop in a plugin, or let Soulsolid build one from git.

Analyze

AcoustID fingerprints, lyrics, file path reorganizing and merging duplicates.

Jobs & webhooks

Everything runs as a background job with logs, and can notify Telegram, ntfy or Emby.

Self-hosted

One container, a SQLite database and a YAML config. Your music stays yours.
