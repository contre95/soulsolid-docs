Everything you can do in the web interface can also be done over HTTP, which makes it easy to automate Soulsolid with curl, scripts or other tools. The web interface and the API use the same addresses: when a request comes from the web interface you get a web page, and when it comes from anything else you get JSON.

Request bodies can be sent as form fields (-d "key=value") or as JSON.

Soulsolid has no authentication: anyone who can reach it can use the API. Don’t expose it to the internet without a reverse proxy that adds a login.

Responses#

Each route below returns one of these kinds of responses:

ResponseWhat you get
PageA full web page. Open it in a browser.
DataThe data shown on that part of the page, as JSON.
ValueA single value: {"key":"…","value":…}.
OK{"message":"…"} on success, or {"error":"…"} with an HTTP error status.
Job202 Accepted with {"job_id":"…"}. The work runs as a background job; follow it with /jobs/:id.
FileThe file itself (audio, image, playlist, database). Send Accept: application/json to get {"type":"…","url":"…"} instead.
JSONAlways JSON.

Search parameters#

ParameterDefaultMeaning
queryText to search for in artists, albums and tracks
page1Page number
limit50Results per page
genreOnly tracks with this genre
has_acoustidtrue or false: only tracks with or without an AcoustID
lyrics_filterOnly tracks in a given lyrics state
lyrics_textOnly tracks whose lyrics contain this text
added_after, added_beforeOnly tracks added in this date range
